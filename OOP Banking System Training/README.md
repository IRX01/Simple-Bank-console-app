# 🏦 OOP Banking System Training

[![C#](https://img.shields.io/badge/Language-C%23-blue.svg)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![.NET](https://img.shields.io/badge/Platform-.NET-512bd4.svg)](https://dotnet.microsoft.com/)

Консольное приложение для симуляции банковской системы, созданное для отработки ключевых принципов **Объектно-Ориентированного Программирования (ООП)**.

## 🎯 Цель проекта
Демонстрация практического применения четырех столпов ООП:
* **Инкапсуляция**: Безопасное управление балансом и историей операций через свойства и методы.
* **Наследование**: Создание специализированных типов счетов на базе основного класса `BankAccount`.
* **Полиморфизм**: Использование `virtual` и `override` методов для изменения логики снятия средств и начисления процентов.
* **Абстракция**: Моделирование сущности банковского счета с выделением только необходимых характеристик.

---

## 🚀 Функциональные возможности

### 1. Типы счетов
Программа поддерживает три вида аккаунтов, каждый со своей уникальной логикой:
* **Обычный счёт (`BankAccount`)**: Базовый функционал — ввод, вывод, просмотр баланса.
* **Накопительный счёт (`SavingAccount`)**: 
    * Снятие средств с комиссией 1%.
    * Автоматическое начисление 1% на остаток каждые 5 секунд (симуляция процентов).
* **Кредитная карта (`CreditCard`)**: 
    * Стартовый лимит 1000 руб.
    * Комиссия за снятие (1% + 50 руб).
    * Механика **Grace Period**: если долг не погашен за 1 минуту, начисляется штраф 5% от суммы долга.

### 2. Банковские операции
* 💰 **Депозит и снятие**: Проверка корректности сумм и наличия средств.
* 🔄 **Внутренние переводы**: Возможность переводить деньги между своими счетами по номеру.
* 📊 **История операций**: Детальный лог всех действий по текущему счёту с указанием времени.
* 📂 **Управление портфелем**: Создание неограниченного количества счетов и быстрое переключение между ними.

## 🏗 Архитектура классов


* **`Program.cs`**: Основной цикл приложения, обработка пользовательского ввода и логика меню.
* **`BankAccount.cs`**: Родительский класс. Содержит общую логику баланса и истории.
* **`SavingAccount.cs`**: Наследник с логикой процентов.
* **`CreditCard.cs`**: Наследник с логикой долга и кредитных условий.
